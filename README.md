# Divine Living

Build a complete, production-quality, pixel-accurate responsive homepage for

“Science Divine – The Science of Divine Living”.

IMPORTANT:

I am providing a reference screenshot of the homepage.

Recreate the visual design extremely closely in terms of:

- typography

- visual hierarchy

- spacing

- image composition

- background treatment

- card proportions

- borders

- colors

- section heights

- button styling

- image overlays

- navigation

- responsive behavior

Do NOT simply use the screenshot as a single background image.

Rebuild every section independently using proper HTML/React components,

editable text, reusable cards, responsive images, backgrounds and overlays.

The final website should feel:

premium, spiritual, peaceful, refined, editorial, elegant, conscious,

minimal and sophisticated — NOT like a generic temple/religious website.

26. VERY IMPORTANT VISUAL RULES

==================================================

1. Navy + ivory + antique gold are the dominant palette.

2. Serif typography is central to the brand identity.

3. Use Cormorant Garamond for all meaningful titles.

4. Use Inter only for functional/body information.

5. Avoid pure black.

6. Avoid overly bright gold.

7. No gradients except subtle photographic overlays.

8. No glassmorphism.

9. No excessive drop shadows.

10. No cartoon spiritual imagery.

11. No generic bright orange Hindu website styling.

12. No unnecessarily huge text.

13. All icons should be fine-line gold icons.

14. Maintain editorial alignment and whitespace.

15. Every section must feel connected to the same premium visual system.
